# program-kasir-cafe-asad-rahied-dan-Shafin-A.r
Program kasir kedai kopi C++ ini menggunakan array untuk menyimpan 9 menu. Fitur utamanya meliputi: sistem keranjang belanja dengan looping, validasi input pesanan (mencegah error), perhitungan total otomatis, diskon Rp15.000 tiap kelipatan belanja Rp100.000, validasi kecukupan uang tunai, dan fitur cetak struk rincian transaksi.
